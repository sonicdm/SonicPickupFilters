# Changelog

## 0.1.1

- Cap is its own checkbox: enable Cap and it fills max stack (or 50); edit the number afterward
- Cap / Block / Qty columns no longer overlap; panel scroll stays put when toggling Cap
- Faster mouse-wheel scrolling in the filter list
- Hotkey works when Enabled is off; Input.GetKeyDown fallback; ignore console/chat/text focus
- AutoReloadConfig reloads `.cfg` while in-game (Enabled / keys / rules without restart)
- Inventory bar button always injects so you can open the panel while filters are disabled

## 0.1.0

- Allow / Block / Cap auto-pickup filters (Cap counts inventory; oversized piles shrink to remaining room)
- In-game Pickup Filter panel (search, category, tabs)
- Inventory modifier + right-click toggles Block
- Inventory bar button and configurable hotkey (default L)
- New Thunderstore icon
